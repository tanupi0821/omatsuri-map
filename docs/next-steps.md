## 積み残し（優先順）

### 1. 別の市が同じ URL を共有している 95 件

**`_citySlug` はエリア定義ではなくファイルの置き場所から決まる**
（`src/lib/data.js` がパスの 2 階層目を使う）。定義に無い市の祭りが
既存のディレクトリへ紛れ込むと、URL だけ共有されてしまう。

- 第 1 段 `scripts/fix-slug-collisions.mjs` … 定義側の重複を解く（147 組 → 実施済み）
- 第 2 段 `scripts/fix-slug-collisions2.mjs` … ファイルの置き場所から解く（32 件実施済み）
- `scripts/import/goguynet.mjs` の `create()` は**使用済み slug を見るよう修正済み**

**残っている原因**: 連番を振る importer が 6 本ある。
`city-ward.mjs` / `goguynet.mjs` / `gotouti.mjs` / `hanabi-nationwide.mjs` /
`summer-nationwide.mjs` / `tsushin.mjs`。**goguynet 以外は未修正**なので、
`npm run collect` のたびに新しい衝突が生まれる。
まず 6 本すべてで「使用済み slug を見る」を共通化し、そのあと
第 2 段を流して収束させること。

なお `/a/kanagawa/kanagawa-006/ → 相模原市緑区, 相模原市中央区` のような
**区が `area.city` に入っているもの**は slug の問題ではなくデータの持ち方の
問題なので、別に扱う。

## 触るときの約束

- **`node scripts/dedupe.mjs --apply` は目で見てから。** 会場が食い違う組は
  統合しない歯止めが入っている（松戸市の「納涼盆踊り」8 件は別々の町会だった）
- **推測で埋めない。** 公園名から住所を起こすのは禁止（「船堀三丁目公園」が
  船堀三丁目にあるとは限らない）。確かめた住所と推測した住所が同じ顔で並ぶと、
  全部の住所が信用できなくなる
- **出典の文章を転載しない。** `description` は全件 null。拾ってよいのは事実の項目だけ
- **`enrich-all` はファイル名順**。正規化は `zz-` で最後尾に置くこと
- 3 体以上で同時に `npm run build` すると `dist/` を奪い合って
  「Cannot find module」で落ちる。`rm -rf dist .astro` して再実行すればよい
